             "frameTime": "2026-11-10 15:30:12.345",

      "rangeStartM": 0, "rangeStepM": 6,
      "freqStartMHz": 14.6484, "freqStepMHz": 0.976562, "zeroWindMHz": 80,
      "spectrum": [[…], …],  // 240 门 × 240 频点
      "radialWind": […],     // 240 门，m/s
      "cnr": […] },          // 240 门，dB
    { "name": "ADC0_15m", … }, { "name": "ADC0_30m", … }
  ]
}

斜距 = 起点 + 门序号 × 门宽；频率 = 起点 + 频点序号 × 间隔。缺测写 null。
